# California Housing Investment Analysis & Predictive Screening Pipeline

## 📌 Project Overview
This project delivers an end-to-end data analytics and predictive screening pipeline built on the **California Housing dataset** for a real-estate investment advisory scenario[cite: 2, 3]. Applying modern ETL and DataOps principles (Bronze $\rightarrow$ Silver $\rightarrow$ Gold architecture)[cite: 1], the project translates raw geographical and demographic data into actionable, client-specific investment recommendations and predictive models[cite: 2, 3].

The pipeline performs automated data validation, exploratory spatial analysis, custom feature engineering, regression modeling, and value-screening to identify high-potential census block groups across distinct investor profiles[cite: 2, 3].

---

## 🏗️ Architecture & Pipeline Design

The repository follows a modular Medallion-style architecture[cite: 1]:

* **Bronze Layer (Ingestion & Data Profiling):** Raw data extraction via Scikit-Learn, schema validation, completeness verification, and artificial cap detection ($MedHouseVal \le \$500k$)[cite: 2, 3].
* **Silver Layer (Transformation & Feature Engineering):** Data cleaning, spatial and demographic correlation studies, and derived ratio engineering (`RoomsPerOccupant`, `BedroomRatio`)[cite: 2, 3].
* **Gold Layer (Analytics & Predictive Modeling):**
  * **Heuristic Scoring Models:** Custom percentile ranking algorithms for Budget (Client A), Premium (Client B), and Space-Oriented (Client C) investors[cite: 2, 3].
  * **Machine Learning Benchmark:** Comparative evaluation of Baseline, Linear Regression, Decision Tree, and Random Forest Regressors using MAE, RMSE, and $R^2$ metrics[cite: 2, 3].
  * **Value Screening (Client D):** Residual and prediction gap analysis ($\text{PredictionGap} = \text{PredictedValue} - \text{ObservedValue}$) with business constraints for identifying potentially undervalued locations[cite: 2, 3].
* **Risk & Strategy Layer:** Comprehensive residual error profiling, spatial error distribution mapping, and investment risk assessment[cite: 2, 3].

---

## 👥 Investor Profiles Addressed

1. **Client A (Budget-Oriented):** Low house values, economically stable median income, and low occupancy density[cite: 2, 3].
2. **Client B (Premium Market):** High median income, high asset valuations, and spacious residential properties[cite: 2, 3].
3. **Client C (Space-Oriented):** Maximized room count, low household crowding, and balanced market price[cite: 2, 3].
4. **Client D (Value Investor):** Positive model prediction gaps combined with solid demographic fundamentals[cite: 2, 3].
